# DirectInv versus LoRA+DirectInv qualitative examples

This shortlist is intended for a qualitative comparison patterned after
Figure 1 of the Direct Inversion paper. Each comparison uses the reproduced
SD1.5 DirectInv output and a fixed, previously reported LoRA+DirectInv
configuration for the editor. No checkpoint was selected separately for an
individual image. The saved annotation panels are ordered as prompt, source,
reconstruction, and edited output; the quantitative editing metrics use the
last tile.

## Recommended examples

| Editor | PIE-Bench ID | Edit | LoRA+DirectInv configuration | Selection rationale |
|---|---:|---|---|---|
| P2P | `111000000005` | Replace the dog with a monkey | cycle r16, lambda 0.5 | Strongest average gain percentile among P2P examples that improve all seven metrics; the LoRA result preserves the illustrated girl and field while performing the replacement. |
| PnP | `423000000000` | Make the carpet floral | cycle r8, lambda 1 | Strongest average gain percentile among PnP examples that improve all seven metrics; the floral edit is clearer and remains localized to the carpet. |
| MasaCtrl | `000000000001` | Change the cake shape to square | cycle r16, lambda 4 | All seven metrics improve, both methods perform the edit, and the LoRA result gives the cleanest visually defensible preservation comparison among the inspected high-ranked candidates. |
| Pix2Pix-Zero | `124000000004` | Change the potted plant to a seated man | cycle r32, lambda 1 | Top-three consistency candidate; all seven metrics improve and LoRA preserves the wall and floor far better while producing the requested person. |

All values below are in the native per-image CSV units. For Structure, LPIPS,
and MSE, lower is better; for PSNR, SSIM, CLIP target, and CLIP edit, higher is
better.

The largest headline gains are:

- P2P: PSNR +8.41 dB, LPIPS -0.216, and CLIP edit +5.64.
- PnP: CLIP edit +4.95 and PSNR +2.64 dB.
- MasaCtrl: PSNR +2.34 dB with smaller gains in every other metric.
- Pix2Pix-Zero: LPIPS -0.210, SSIM +0.218, CLIP target +5.12, and CLIP edit +8.19.

## Maximum-gap alternatives

For a figure that explicitly emphasizes the largest visually defensible
single-metric gap rather than seven-metric consistency, use:

- P2P `123000000006`, notebook to calendar: CLIP edit improves from 15.03
  to 23.94 (+8.91), and all six other metrics also improve.
- PnP `924000000009`, stained-glass style: CLIP target/edit improves from
  20.83 to 34.53 (+13.70), but Structure worsens because the stronger style
  transformation changes more of the image.
- MasaCtrl `111000000003`, bunny to pig: LPIPS falls from 0.232 to 0.122,
  Structure falls from 0.120 to 0.059, and CLIP edit rises by 2.74; PSNR, MSE,
  SSIM, and whole-image CLIP target worsen, so these trade-offs must be shown.
- Pix2Pix-Zero `124000000004`, plant to seated man: this is already the
  recommended consistent example.

Absolute CSV maxima that did not visibly perform the requested edit were
discarded. This prevents a CLIP or mask outlier from becoming the qualitative
headline.

## Same-input alternatives

If the final layout must use the same PIE-Bench inputs across every editor,
the strongest visually inspected shared candidates are:

1. `123000000006`: replace the notebook with a calendar.
2. `913000000005`: add a black-and-white ink-painting style to the empty room.
3. `721000000001`: change the robin to a silver robin sculpture.

These are less uniformly convincing across all four editors than the
editor-specific recommendations above. In particular, some editors do not
perform the requested change even when a preservation or CLIP metric improves.
