\noindent All rows use the 700-image PIE-Bench set. Unedited-region metrics use 556 images; the other metrics use 700. The partial-depth runs use the same rank-16 SD1.5 Moonwalker checkpoint and 50-step DDIM schedule, stopping inversion after the stated fraction and denoising from that point. DDIM and DirectInv are reproduced baselines; P2P uses the FP32 reproduction. Values are not original-paper numbers. Within each editor, bold marks the best displayed value for each metric; underlining marks values strictly better than the reproduced DirectInv baseline for that metric.
